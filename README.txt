GENERAL STORE MANAGER — ANDROID PWA

FEATURES
- Add product names in Telugu or English.
- Set purchase rate per kg/litre/unit.
- Set profit as fixed rupees or percentage; selling price is calculated automatically.
- Billing supports grams/ml, rupee amount, or pieces/units.
- Stock decreases automatically after completed bills and increases on purchase entries.
- Cash, UPI and credit payment labels.
- Expenses, other income, owner cash in/out.
- Date-range sales, cost, gross profit, expenses and net operating profit reports.
- Print receipt and share bill text using Android share menu.
- Offline-ready after the first successful load.

INSTALL ON ANDROID
1. Upload/extract this folder to a static HTTPS host (for example GitHub Pages, Netlify, or your own HTTPS hosting).
2. Open the hosted website in Chrome on Android.
3. Tap Chrome menu (⋮) > Install app or Add to Home screen.
4. Open it from the new home-screen icon.

IMPORTANT
- Data is stored in this browser/device using localStorage. It is not automatically synced to another phone and can be lost if browser site data is cleared. Use Export backup regularly.
- This starter version does not include cloud sync, login, barcode scanning, supplier/customer ledgers, or a real payment gateway.
- Product quantity is stored in kg/unit. For loose goods, use purchase and stock quantities in kg; the bill can be entered in grams or rupee value.
- A rupee-based bill entry calculates equivalent quantity using the product's selling rate. The bill total remains the amount entered.
- Profit reports use the product purchase cost saved on each bill. If a product cost changes later, old bills retain their original cost.
- No GST is added. Please use only in accordance with your applicable tax and invoicing obligations.
